# 📝 TaskManager – Django & React

Ein vollständiger Aufgabenmanager mit Django REST API und React.

## 🚀 Funktionen

- ✔️ Aufgaben hinzufügen
- ✔️ Aufgaben aus einer Django-API abrufen
- ✔️ Dynamische Benutzeroberfläche mit React
- ✔️ REST-API-Integration

## 📸 Vorschau

![screenshot](./screenshots/preview.png) <!-- Du kannst einen "screenshots"-Ordner hinzufügen -->

## 🛠️ Tech-Stack

- 💻 Backend: Django 5.2 + Django REST Framework
- 🌐 Frontend: React 18
- 🔗 REST-API
- 🗃️ SQLite

## 🔧 Installation

### 1. Repository klonen

```bash
git clone https://github.com/dein-nutzername/taskmanager.git
cd taskmanager
```
